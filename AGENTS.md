# AGENTS.md

Refer to the [CLAUDE.md](./CLAUDE.md) in this folder for the full project overview, architecture, conventions, and guidance.

## Agent Guidelines

- Use relevant Codex skills before or during work whenever the task matches them. Available skills include: `commit`, `code-review`, `simplify`, `claude-api`, and others listed in the agent's skill registry.
- Use `CLAUDE.md` as the canonical source for project structure, build and test commands, and coding conventions.
- If `AGENTS.md` and `CLAUDE.md` differ, follow `AGENTS.md` for agent-specific behavior and treat `CLAUDE.md` as the general project overview.

## BDD Workflow

- This project uses Playwright BDD. After adding or modifying any `.feature` file, always run `npx bddgen` to regenerate the spec files before running tests.
- Playwright executes the generated specs in `.features-gen/`, not the `.feature` files directly.

## Do Not

- **Do not edit `.features-gen/`** — these files are auto-generated by `bddgen` and will be overwritten.
- **Do not commit generated artifacts** — the following directories are generated and should never be committed: `reports/`, `.features-gen*/`, `test-results/`, `blob-reports/`, `logs/`, `.auth/`, `.locks/`.
