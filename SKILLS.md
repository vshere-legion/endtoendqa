# Claude Code Skills — Legion Playwright Framework

Custom slash commands available in Claude Code for this project. Type `/` in the chat input to see all commands.

---

## Framework Skills

### `/run-tests`
Run Playwright tests with dynamic options.

```
/run-tests
/run-tests team=sch
/run-tests team=sch env=rc browser=chromium
/run-tests team=sch env=rc tags=@P1-Critical workers=4
/run-tests team=sch env=rc browser=firefox headed
```

| Option | Values | Default |
|---|---|---|
| `team` | sch, TA, PLT-Core, PLT-Int, PLT-Ops, LRB, EV-Com, EV-LIP, EV-ELM, GENAI, EPR | all |
| `env` | dev, staging, rc, uat, prod | rc |
| `browser` | chromium, firefox, webkit | chromium |
| `tags` | `@P1-Critical`, `@Regression`, `@smoke`, etc. | none |
| `workers` | any number | 2 |
| `headed` | flag (no value) | headless |

Always runs `npx bddgen` first automatically before executing tests.

---

### `/bddgen`
Regenerate Playwright BDD spec files from Cucumber `.feature` files.

```
/bddgen
/bddgen team=sch
/bddgen --dry-run
/bddgen team=sch --dry-run
```

Always run this after modifying any `.feature` file. Generated specs go to `.features-gen/` (do not edit directly).

---

### `/new-team`
Scaffold a new team directory with the standard structure.

```
/new-team EV-Analytics
/new-team PLT-Perf
```

Creates: `teams/<TEAM>/features/ui/`, `features/api/`, `steps/`, `pages/`, `api/`, `utils/`, `test-data/`, `config.ts`, `README.md`

> After scaffolding: add the team name to `config/framework.config.ts` and create credentials in `test-data/users/`.

---

### `/new-feature`
Scaffold a new Cucumber feature file and verify it generates a valid Playwright spec.

```
/new-feature sch login-flow
/new-feature TA overtime-report
/new-feature PLT-Core api-health-check --type=api
```

Creates the `.feature` file, runs `npx bddgen` to verify, and shows next steps for step definitions.

---

### `/code-quality`
Run the full code quality pipeline: TypeScript typecheck + ESLint + Prettier.

```
/code-quality
/code-quality fix
```

`fix` mode auto-corrects lint and format issues. Reports a pass/fail summary table for all three checks.

---

### `/rerun-failed`
Rerun failed scenarios from the last test run (`reports/rerun.txt`).

```
/rerun-failed
/rerun-failed --retries 2
/rerun-failed --retries 2 --workers 4
/rerun-failed --headed --verbose
```

Requires `reports/rerun.txt` to exist (generated by sharded runs + `npm run merge-reports:failures`).

## Playwright MCP Skills

These skills use the **Playwright MCP Server** for live browser control. The server is pre-configured in [.mcp.json](.mcp.json).

### `/playwright-generate-test`
Explore a page (optionally via live browser) and generate a BDD `.feature` file + `.steps.ts` following Legion conventions.

```
/playwright-generate-test team=sch scenario="Verify schedule page loads with correct week label"
/playwright-generate-test team=TA url=https://rc-enterprise.dev.legion.work/ scenario="View timesheet for current week"
```

Generates:
- `teams/<team>/features/ui/<feature>.feature` — tagged with priority, team, suite
- `teams/<team>/steps/<feature>.steps.ts` — with fixture pattern, logger, testContext
- Runs `npx bddgen` to verify compilation

---

### `/playwright-explore-website`
Navigate to a Legion page and produce a BDD test plan with Gherkin scenarios.

```
/playwright-explore-website url=https://rc-enterprise.dev.legion.work/ team=sch
/playwright-explore-website url=https://rc-enterprise.dev.legion.work/schedule team=sch feature=schedule-overview
```

Identifies 3–5 user flows, documents selectors, and outputs ready-to-use Gherkin scenarios.

---

### `/playwright-fill-form`
Automate filling in a form using Playwright MCP. Pauses for human review before submitting.

```
/playwright-fill-form url=https://forms.example.com/my-form name="John Doe" email="john@legion.work"
/playwright-fill-form url=https://rc-enterprise.dev.legion.work/form field1="value1" field2="value2"
```

**Never submits without explicit confirmation.** Shows a review summary and screenshot before any submission.

## Quick Reference

| Goal | Command |
|---|---|
| Run smoke tests for SCH team | `/run-tests team=sch tags=@P1-Critical` |
| Run full regression | `/run-tests env=rc tags=@Regression workers=8` |
| Regenerate specs after editing a feature | `/bddgen team=sch` |
| Add a new team | `/new-team <TEAM-NAME>` |
| Add a new feature to an existing team | `/new-feature <team> <feature-name>` |
| Check code before committing | `/code-quality` |
| Auto-fix lint and format | `/code-quality fix` |
| Retry failures from last run | `/rerun-failed` |
| Explore a page and plan tests | `/playwright-explore-website url=<url> team=<team>` |
| Generate a test from description | `/playwright-generate-test team=<team> scenario="<desc>"` |
