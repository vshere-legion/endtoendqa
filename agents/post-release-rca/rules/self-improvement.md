# Self-Improvement Rules

## Session Start
At the start of every new session or conversation:
1. Read `tasks/lessons.md`
2. Note any lessons relevant to the current project or task
3. Apply all rules from lessons proactively — don't wait to be corrected again

## On User Correction
When the user corrects any behavior:
1. **Acknowledge** the correction briefly
2. **Update** `tasks/lessons.md` with a new lesson entry
3. **Apply** the correction immediately in the current session
4. **Never repeat** the same mistake in this or future sessions

## Escalation
If a lesson category appears 3+ times:
- Extract it into a dedicated `rules/*.md` file
- Remove the individual lessons from lessons.md (they're now a rule)
- Reference the new rule file in CLAUDE.md

## Metrics to Track
- Total lessons captured
- Lessons by category (Language, Connection, Report, Analysis, UX)
- Repeat mistakes (should be 0 after the lesson is written)

## Anti-Patterns to Avoid
- Don't apologize excessively — acknowledge once, fix, move on
- Don't explain why the mistake happened — just capture the rule
- Don't wait for the user to remind you — proactively check lessons
