# Skill: Node 3C — Test Script Review Evaluation

## Identity
- **Name:** `node3c-script-review`
- **Type:** Evaluation Module (Skill)
- **Layer:** 2 — DAG Node 3C
- **Invoked by:** Layer 2 DAG Conductor after Node 3 completes

## Purpose
Review Playwright test scripts generated by Node 3 for locator quality, maintainability, and adherence to the strict locator priority rules. Rejects scripts with forbidden selectors and loops back to Node 3 for remediation.

## Evaluation Rules

### 1. Locator Priority Enforcement (STRICT)
- **Priority 1 — PREFERRED:**
  - `getByRole()` — ARIA roles (button, link, heading, textbox, etc.)
  - `getByText()` — visible text content
  - `getByLabel()` — associated label text
  - `getByTestId()` — data-testid attributes
- **Fallback — ALLOWED:**
  - CSS selectors — ONLY with dynamic/semantic selectors (class-based, attribute-based)
  - NO hardcoded values in CSS selectors
- **BANNED — INSTANT REJECT:**
  - `xpath` / `XPath` — any XPath usage
  - Hardcoded IDs (`#specific-id-123`)
  - Fragile selectors (nth-child, deep nesting, auto-generated classes)
  - `page.locator('div > span:nth-child(3)')` — positional selectors
- **Action on fail:** REJECT with specific locator replacement suggestions
- **Severity:** CRITICAL

### 2. Hardcoded Value Detection
- **Check:** No hardcoded URLs, credentials, or environment-specific values
- **Check:** All test data should use fixtures or environment variables
- **Action on fail:** REJECT — "Hardcoded value detected at line X"
- **Severity:** CRITICAL

### 3. Assertion Quality
- **Check:** Every test must have at least one `expect()` assertion
- **Check:** Assertions should be specific (not just `toBeVisible()` everywhere)
- **Check:** Recommended patterns:
  - `toHaveText()`, `toHaveValue()`, `toHaveAttribute()`
  - `toBeEnabled()`, `toBeDisabled()`, `toBeChecked()`
- **Action on fail:** WARNING — "Weak assertions detected"
- **Severity:** WARNING

### 4. Test Structure
- **Check:** Tests use `test.describe()` for grouping
- **Check:** Proper `beforeEach` / `afterEach` for setup/teardown
- **Check:** No test interdependencies (each test can run independently)
- **Action on fail:** WARNING — "Test structure improvement needed"
- **Severity:** WARNING

### 5. Wait Strategy
- **Check:** No `page.waitForTimeout()` (hardcoded waits)
- **Check:** Should use auto-waiting or explicit wait conditions:
  - `page.waitForSelector()`, `page.waitForResponse()`
  - Playwright's built-in auto-wait on actions
- **Action on fail:** REJECT — "Hardcoded wait detected at line X"
- **Severity:** CRITICAL

## Iteration Loop
| Iteration | On Rejection | Action |
|-----------|-------------|--------|
| 1 | REJECTED | Return fix instructions → Node 3 remediates scripts |
| 2 | REJECTED | Return fix instructions → Node 3 remediates scripts |
| 3 | REJECTED | BLOCK pipeline — escalate to `#qa-alerts` for manual review |

## Downstream
- **On APPROVED** → Node 4 (Execute Test Suite)
- **On REJECTED (iter < 3)** → Loop back to Node 3 with remediation instructions
- **On REJECTED (iter = 3)** → Pipeline blocked, Slack alert
